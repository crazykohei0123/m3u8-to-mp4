# プライバシーポリシー

対象拡張: **m3u8 to MP4 (local ffmpeg)**
最終更新日: 2026-11-17

## 概要

本拡張は、ユーザーの PC 上で動作するローカルツールです。開発者のサーバーは存在せず、**いかなるデータも外部へ送信しません**。

## 取得・利用する情報

| 情報 | 目的 | 送信先 |
|---|---|---|
| ページ内の通信 URL（HLS プレイリストの URL） | 変換対象のプレイリストを検出するため | なし（ブラウザ内およびローカルホストのみ） |
| 応答本文の先頭 64 バイト | URL に `.m3u8` が無いプレイリストかを判定するため | なし |
| 設定値（ffmpeg のパス、出力フォルダ、ファイル名、Referer、User-Agent など） | 変換設定の保存 | `chrome.storage.local`（端末内のみ） |
| Cookie（任意・既定 OFF） | ユーザーが ON にした場合のみ、ログイン必須サイトのプレイリストをローカルの ffmpeg が取得できるようにするため | 端末内の ffmpeg プロセスにのみ渡す |
| 変換ログ・進捗 | 画面表示 | なし |

- 閲覧履歴・入力内容・個人情報を収集しません。
- アクセス解析（アナリティクス）、広告、トラッキングの仕組みを含みません。
- 変換はすべて端末内の ffmpeg で行われ、動画データが開発者や第三者へ送られることはありません。

## ローカルアプリケーションの利用

本拡張は、端末内のネイティブホスト（`m3u8host.exe`）と通信し、ユーザーが指定した `ffmpeg.exe` を起動します。
この通信はブラウザの Native Messaging 機構によるもので、外部ネットワークへは送信されません。

## データの削除

設定は、拡張機能の削除（`chrome://extensions` / `vivaldi://extensions` からの削除）で消去されます。
変換途中の一時ファイルは `%TEMP%\m3u8-to-mp4` に作成され、ジョブ終了時に削除されます。
